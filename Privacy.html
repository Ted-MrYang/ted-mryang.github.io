隐私政策

生效日期：2026年11月6日　｜　最后更新：2026年11月6日
拾光·Moment（以下简称“本应用”或“我们”）重视您的个人信息和隐私保护。 本政策用于说明您使用本应用的照片整理、珍藏图册、照片分组、随机回忆、 按日期浏览、批量清理及 Face ID 解锁等功能时，相关信息如何被访问、使用和保护。 请您在使用本应用前仔细阅读本政策。

一、我们如何访问和处理您的信息

1. 照片和视频资料

为实现照片浏览、随机回忆、珍藏、分组和批量清理等功能，本应用需要在您授权后访问 iPhone 照片图库。根据您授予的系统权限，本应用可能访问：

  • 照片或视频内容：用于在应用内展示、选择、整理或执行您主动发起的清理操作。
  • 照片属性信息：例如拍摄日期、媒体类型及系统提供的其他照片属性，用于按日期浏览和照片整理。
  • 您的操作选择：例如您选择加入珍藏图册、创建分组或选择清理的照片。

照片访问权限由 iOS 系统管理。您可以在 iPhone“设置”中调整本应用的照片访问范围，包括仅允许访问所选照片或允许访问全部照片。未获得相应授权时，相关功能可能无法正常使用。

2. 照片整理与批量清理

本应用仅会根据您主动进行的操作整理照片。批量清理功能用于帮助您选择不再需要的照片，并通过 iOS 系统提供的照片管理机制发起删除操作。删除照片可能需要您在系统弹窗中再次确认；照片是否最终删除以及是否仍可在“最近删除”中恢复，以 iOS 照片图库的实际状态为准。

请在删除前仔细核对所选内容。对于您主动确认删除的照片，请您自行确认是否已备份重要资料。

3. Face ID 信息

如果您开启 Face ID 解锁，本应用会调用 Apple 提供的本地身份验证能力，用于确认是否允许进入应用。面容特征数据由 iOS 系统安全处理，本应用不会读取或保存您的面容图像、面容模板或 Face ID 生物识别数据。身份验证结果仅用于应用内解锁。

4. 设备及应用设置

为保存您的使用偏好，本应用可能在设备本地保存排序方式、外观主题、语言选择、珍藏状态和分组等设置或应用数据。这些信息用于维持应用功能和使用体验。

二、信息的使用目的

我们访问或处理相关信息，仅用于提供和改进本应用功能，包括：

  • 展示照片及按日期浏览照片；
  • 提供随机回忆、珍藏图册和照片分组功能；
  • 根据您的选择执行照片批量清理；
  • 保存应用主题、语言及排序等个性化设置；
  • 通过 Face ID 为应用提供本地解锁保护；
  • 保障应用正常运行、排查故障及维护服务安全。

三、信息的存储与传输

本应用的照片浏览、整理和选择操作基于 iOS 照片图库及设备本地功能实现。除非应用内另有明确说明并取得必要授权，我们不会主动将您的照片或视频内容上传至我们的服务器，也不会将照片内容用于广告画像或出售给第三方。

应用设置及整理过程中产生的数据可保存在您的设备本地。您卸载本应用后，应用沙盒内的数据可能随之被系统清除；照片图库中的原始照片则按照 iOS 照片图库的管理规则处理，不因卸载应用而当然删除。

四、信息共享与第三方服务

我们不会出售您的个人信息。除以下情形外，未经您的同意，我们不会向无关第三方提供您的个人信息：

  • Apple 系统服务：本应用使用 iOS 提供的照片访问、照片管理和 Face ID 等系统能力。相关权限请求及系统处理由 Apple 按其规则提供。
  • 法律法规要求：在法律法规、司法机关或行政主管部门依法提出要求时，我们可能在必要范围内提供相关信息。
  • 保护合法权益：为保护您、我们或其他用户的合法权益，在法律允许的范围内采取必要措施。

如果未来版本接入新的第三方 SDK、云服务、广告或统计服务，我们会根据实际功能更新本政策，并在适用法律要求时另行取得您的授权或同意。

五、权限管理与撤回授权

您可以随时通过 iPhone“设置”管理本应用的照片访问权限。您也可以在本应用设置中关闭 Face ID 解锁。撤回权限后，本应用将无法继续使用依赖相应权限的功能，但不影响撤回前已依法完成的处理活动。

六、您的权利

在适用法律规定的范围内，您可以：

  • 通过 iOS 系统设置查看、调整或撤回照片访问权限；
  • 在应用内查看、修改或删除您创建的分组及相关整理设置（如该版本提供相应操作）；
  • 关闭 Face ID 解锁功能；
  • 就个人信息处理相关问题向我们提出咨询、意见或请求。

七、未成年人保护

本应用并非专门面向未成年人提供服务。若您是未成年人的监护人，并认为未成年人在未取得适当监护人同意的情况下向我们提供了个人信息，请通过本政策所列联系方式与我们联系。我们将在核实后依法处理。

八、隐私政策的更新

我们可能根据应用功能、服务方式或法律法规的变化适时更新本政策。更新后的政策将在本页面发布，并注明更新日期。如涉及重大变更，我们会在适当位置以合理方式提示您。您在更新生效后继续使用本应用的，表示您已阅读更新后的政策；法律另有要求的，从其规定。
